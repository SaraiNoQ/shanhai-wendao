## 文档规则

- 使用简体中文和 UTF-8；文件名除 GDD 外使用小写英文连字符。
- 一个事实只保留一个来源，其他文档使用链接引用。
- 规则使用“必须／不得”，建议使用“建议”，未决定事项明确写为“待验证”。
- 数值必须写单位、上限、舍入方式和适用范围。
- 示例不能引入正文尚未定义的机制。
- 修改文档时更新内容，不维护手写变更日志；版本节点由 Git 记录。

## 暂不创建的文档

以下文档只有触发实际需求时才创建：

- `save-format.md`：出现第二个 `saveVersion` 或首次存档迁移时。
- `balance-notes.md`：开始记录真实试玩数据时。
- `release-checklist.md`：准备发布可下载版本时。
- API 文档：出现网络服务时；当前单机原型没有 API。
