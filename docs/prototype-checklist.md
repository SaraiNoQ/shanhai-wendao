# 原型验收清单

本清单用于判断炼气至筑基垂直切片是否完成。详细规则见 [GDD 第 16 节](东方志怪放置卡牌_GDD_v0.1.md#16-垂直切片验收标准)。

## M0：文档与项目基线

- [x] GDD v0.1 完成。
- [x] `AGENTS.md`、技术架构和内容数据规范完成。
- [x] 最小 React + TypeScript + Vite 应用可安装、检查和构建。
- [x] `README.md` 记录唯一有效命令。

## M1：卡桌战斗

- [x] 主将、两只妖灵和单个敌人可以完成一场战斗。
- [x] 灵力、四张手牌、抽牌、弃牌和洗牌规则生效。
- [x] 六张起始牌可拖拽设置自动优先级。
- [x] 同一输入和种子重复运行得到相同事件日志与结果。

## M2：三套构筑

- [x] 剑意、符印和灵契规则完成。
- [x] 3 种武器、3 部功法、6 只妖灵和 24 张牌可用。
- [x] 三种纯流派均能完成原型战斗。
- [x] 飞剑镇符、灵使敕令、双灵剑阵能够实际触发。

## M3：收藏养成

- [x] 配装槽、图鉴、等级、免费重置和重复转精华完成。
- [x] 12 件装备、6 件法宝、6 种消耗品配方可收集、升级和配装。
- [x] 装备重铸先预览后确认，不产生同名仓库副本。
- [x] 存档可导出、导入，错误导入不会覆盖当前进度。

## M4：挂机主线

- [x] 30 个槐阴古道关卡均有稳定 ID、1–3 波配置、推荐标签、固定解锁和奖励。
- [x] 13 种敌人行为、目标选择、召唤和死亡触发均有确定性测试覆盖。
- [x] 在线自动、手动接管和离线模拟复用同一战斗核心；失败后停止撞关并刷取最后稳定关卡。
- [x] 离线结算最多 24 小时，时间倒退按 0 处理，模拟不会越过第 30 关劫境入口。
- [x] 第 30 关胜利只解锁劫境并暂停，不自动完成筑基。
- [x] 离线报告能解释伤害、治疗、护盾、Combo、奖励、战斗次数和失败原因，归因覆盖率达到 90%。
- [x] 首次奖励、重复掉落、连续 5 次重复后的未拥有优先和报告领取均幂等。
- [x] v1/v2/v3 存档迁移至 v4 保留收藏与养成；损坏导入不覆盖当前存档。
- [ ] 一次合理升级流程在 2–4 小时逻辑时间内解锁第 30 关；无升级流程会在中段卡关。

## M4.5：可读性、卡关与交互修复

- [x] 自动出牌跳过无合法目标的卡牌，死亡妖灵不会被选为灵契或指定目标。
- [x] 手动接管保留胜负结果，明确提供结算与重试；失败后持久记录失败关、原因和回退关。
- [x] 推进失败继续稳定刷取并显示首屏卡关提醒；稳定关失败、第 1 关暂停和离线待领取状态均有明确反馈。
- [x] 地图节点有独立选中态，侧栏明确区分查看关卡与当前推进关。
- [x] 暗色古卷高对比样式、禁用原因、久战预警和键盘反馈完成。
- [x] saveVersion 4 支持 v1/v2/v3 安全迁移，离线报告不会重复结算。
- [x] 在 1280×720、1440×900、1920×1080、2560×1440 和移动断点完成浏览器人工验收。

## M5：突破劫境

- [x] 7×7 地图固定生成 26 个连通格，并始终存在两枚劫印至首领门的可完成路径。
- [x] 行炁、迷雾、劫印和八类格子生效；事件每局只处理一次。
- [x] 临时牌组最多 12 张，支持同名上限、单实例升级、耗用和战后清理。
- [x] 保存退出后可继续；成功、失败和撤退奖励均先预览、按唯一来源一次领取。
- [x] 千年槐姥三阶段可被三种纯流派和三种混合构筑击败，速度倍率不改变规则结果。
- [x] 22 条志怪录、12 件核心收藏/劫境素材和 `saveVersion: 4` 劫境迁移已接入。

## M6：体验与素材

- [ ] 普通战斗多数为 45–75 秒，关键出牌间隔约 8–12 秒。
- [ ] 一局劫境首次体验为 15–25 分钟。
- [x] 17 件 M4 主线正式像素素材完成尺寸、透明通道、像素颗粒、无伪文字和小尺寸可读性检查。
- [ ] 核心精修卡面、统一卡框、主背景和必要音效替换占位素材。
- [ ] 关键词不只依赖颜色，支持提示、字号和减弱动态设置。

## M5.5：角色、章节地图与渲染性能

- [x] 角色管理页集中处理装备、背包、六张起始牌、优先级、升级、重置和重铸。
- [x] 60 件收藏、14 种敌人、8 个怪谈和 30 个关卡均有精确详情与等级预览。
- [x] 三章线性地图各显示 10 个节点，章节锁定和左右切换符合 0/10/20 解锁边界。
- [x] PixiJS 地图/战斗视觉层、DOM 无障碍交互和静态回退均可用。
- [x] 指纹资源长期缓存、像素素材短期缓存、入口/Worker 体积预算通过；不引入 WASM。

## M5.6：角色布局与数值可读性

- [x] 角色页六个主装备槽改为左右三槽，人物立绘不遮挡任何真实槽位。
- [x] 妖灵、法宝丹药和术法改为独立页签，拖拽、点击和键盘操作继续共用配装规则。
- [x] 统一有效护体、伤害明细、普攻 DPS 和基础战力计算，角色页与战斗使用同一公式。
- [x] 60 件收藏文案与 `effectParams`、战斗行为一致，破煞符攻势恢复和同标签减费有测试覆盖。
- [x] 1280×720、1440×900、1920×1080 和 2560×1440 下完成人物/槽位无重叠验收。

## 发布垂直切片前

- [ ] 所有自动检查通过。
- [ ] 新存档完整走通命名、推图、养成、劫境和筑基。
- [ ] 刷新、关闭网页和错误存档不会复制奖励或损坏进度。
- [ ] 没有加入第二境界、联网、付费、多人或运行时 AI。
